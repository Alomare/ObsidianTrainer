# Obsidian Trainer

An in-game menu for HELLDIVERS (2015) that changes the character, weapons, stratagems, enemies, missions and game data, for the [Obsidian](https://github.com/Alomare/ObsidianLauncher) mod manager.

Missions add nothing to the save while the Trainer is on, and it stays out of the Galactic War. It offers only the base game and owned DLC.

## How to use

1. Switch on Obsidian Trainer in the Mods tab. [Obsidian API](https://github.com/Alomare/ObsidianAPI) turns on with it.
2. Deploy, then start the game.
3. Press **F6** to open the menu. The key can be changed in the Keys tab of Obsidian API.

The Obsidian Trainer page in the Wiki of Obsidian lists every key and page.
